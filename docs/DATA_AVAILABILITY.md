# Data availability

The curated Dawenkou digitization collection is distributed through the
versioned Release associated with this repository. It comprises 41 manually
reviewed colored watertight models, 4,620 registered reconstruction input
images, foreground masks and original COLMAP sparse geometry and camera
parameters. The collection includes 40 ceramic artifacts and one stone
artifact. Object indexes, ID mappings, checksums and validation tools are
available in the Git repository; the complete model and multiview files are
provided as Release assets under CC BY-NC 4.0.

The completed hidden surfaces and transferred color are inferred outputs,
not independently measured geometric ground truth. No independent
train/validation/test split or calibrated common physical scale is asserted.
Full frozen training/intermediate artifacts are outside this minimal data
release. No DOI has been assigned.
